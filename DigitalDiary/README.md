# Diary Application

## Project Overview

This project is a Python diary application that allows users to create, save, load, and view dated diary entries.

Each diary entry is saved as a separate line in a text file. Users can choose which file will be used as the diary file and can switch between different diary files when needed.

## Features

The application allows users to:

- Create a dated diary entry
- Save each diary entry as a separate line in a text file
- Select which text file will serve as the diary file
- Load and switch between different diary files
- Filter diary entries by date
- Print diary entries that match a selected date
